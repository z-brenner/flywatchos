# CX60: a host-only published-topology explorer

CX60 retains the **60 connected representative model populations and all 326
edges** from the Drosophila heading model of Pisokas, Heinze and Webb,
[eLife (2020)](https://doi.org/10.7554/eLife.53985). It is not an individual-neuron
EM connectome. Multiple anatomical cells are represented by each population.
The source's 62 × 62 matrix has two completely empty rows/columns, which are
padding, not additional neuron classes. The live interface exposes 60 real
model units inside its original 64-entry activation buffer.

## What comes from the publication

- Population ordering: P-EN 0–15, P-EG 16–33, E-PG 34–51, Delta7 52–59
- Every nonzero directed connection, without pruning
- Five fitted signed connection strengths, stored at full source precision
- E-PG cue-sector mapping and P-EN half-population input targets

The original MAT stores **category labels**, not strengths or synapse counts.
It is indexed `[target, source]`. The upstream driver transposes it before
passing it to a simulator that sums incoming matrix columns. The category
mapping is preserved in the manifest and generated C table.

Pinned source commit: `dfb95dfeaad0da2df0f7f687846d4df44079a483` in
[the authors' repository](https://github.com/johnpi/eLife_Pisokas_Heinze_Webb_2019/tree/dfb95dfeaad0da2df0f7f687846d4df44079a483).
Unchanged upstream artifacts, full MIT license, derived CSV, nodes and SHA256
manifest are in `data/pisokas2020/`. The full license also travels in the
standalone lab's model metadata.

## What is deliberately our approximation

This is a deterministic **rate-relaxation adaptation**, not a reproduction of
the paper's spiking or tanh-current dynamics. With activity represented as
nonnegative Q10 values, each synchronous step computes:

```
q = round(published_signed_strength * 1024 / 100)
drive_total = stimulus + trunc(sum(q * previous_activity) / 1024)
next_activity = floor((3 * previous_activity + clamp(drive_total, 0, 16383)) / 4)
```

Rounding is nearest, with half away from zero. Signed division in the
recurrent term truncates toward zero; all other divisions have nonnegative
numerators. Maximum per-target accumulator is safely inside int32. The model
has no floating-point dynamics, RNG, allocation, wall clock or I/O. Raw source
strength getters use double solely to preserve published values for inspection.

The global gain 1/100, leak 3/4, clipping, triangular cue profile and input gains
are engineering choices. One step is abstract model time, not milliseconds;
activity is not measured Hz. The baseline's watch sensors and key policy
telemetry remain available but do not drive CX60. Likewise CX60 controls do not
affect baseline Brain64 dynamics.

The published rate model instead uses a tanh current transfer, electrical
parameters, 0.03 times the published weights after dimensionless rescaling,
and noise. This adaptation does not claim self-sustained attractor fidelity,
physical angular-velocity integration, calibrated compass heading, biological
behavior, consciousness or a whole fly brain. Automated cue-off tests establish
that this adaptation's activity decays to zero.

## Inputs and readout

`fly_lab_set_stimulus(angle, strength, turn)` accepts angle 0–359 degrees,
strength 0–1024, and dimensionless turn drive −1024–1024. Invalid input is
rejected atomically. The cue drives E-PG units with a triangular profile of
90-degree half-width and peak strength × 8. Positive turn drive stimulates
P-EN-A indices 0–7; negative stimulates P-EN-B indices 8–15, at magnitude × 4.
The source comments conflict on hemisphere names, so A/B is intentional: the
sign does not promise clockwise or counterclockwise rotation.

Each nine-column E-PG half maps to `[0,45,90,135,180,225,270,315,0]` degrees.
Readout averages redundant units per sector before choosing the strongest
sector. Sector 0 has four units, others have two. This prevents a duplicate
count bias. Each sector mean is integer-truncated before selection. The
lowest-angle sector wins positive ties; no positive truncated sector mean
yields −1, even when tiny residual raw E-PG activity remains. Exact silence
must be checked from raw activations. The result is a coarse 45-degree
model-relative activity peak, not a population-vector or biological heading
measurement. Strength is the winning sector's integer mean Q10 activity.

Model reset initializes zero activity, cue angle 0, strength 768 and turn 0.
The seed argument has no effect in CX60 because the model is noiseless. Legacy
`fly_lab_reset(seed)` always returns to the exact original seeded Brain64.
Pixel and activation pointers remain stable across model switches. All four
unused activation slots are zero. The CX60 watch-sized preview is an abstract
8 × 8 activity-tile projection without baseline anatomical or behavior labels.

## Reproducibility and tests

`python flyos/tools/generate_cx_data.py --check` verifies source hashes and the
entire generated C table. `--check` never modifies files. Both this verifier
and the optional MAT exporter reject optimized Python, because integrity
assertions must not be removed. The Wasm builder runs the verifier before
compiling and records model/data/license hashes in its manifest.

`python flyos/tests/test_cx_provenance.py` tests exact edge directions and
category counts, metadata, license, stale/tampered artifacts and optimized
Python failure. When SciPy is available, it independently reruns MAT → CSV
extraction in a temporary directory and requires byte-identical outputs.

Native tests cover source-defined input populations, every cue sector,
redundant-sector normalization, cue-off decay, unsigned activity bounds,
zero padding, deterministic dynamics, model changes, invalid arguments and
preserved key/pulse ownership. The Node differential test compares native C
and Wasm activations, every pixel and scalar, all edge endpoints, published
strengths and implemented coefficients. These establish implementation
consistency, not biological validity. Nothing changes a target structure,
firmware hook, update package, watch address, private gate or device.
