03 / Keep the provenance

Test a model response, not a claim about a fly.

The published Pisokas et al. (2020) model maintains activity after cue removal and shifts it under one-sided P-EN input. In our cue-loss trial, with synthetic drive also zero, this fixed-point adaptation’s activity decays to zero. Cue plus P-EN-A/B drive supplies one cue and one population drive, not two landmarks. These experiments compare the implemented model; they do not reproduce validated heading behavior. The Hulse measured-anatomy lens is separate and does not drive these dynamics.

Watch for limits: With the cue and synthetic drive both removed, activity can decay to zero. Synthetic P-EN A/B drive can change the profile while the strongest sector stays fixed. Restoring inputs does not guarantee identical states. No persistent heading memory, calibrated turn response or validated path integration is assumed.

Readout definitions, comparison boundaries & sources
  • Strongest sector is the C readout over eight integer E-PG sector means at 0°, 45°, …, 315°. Ties select the lowest angle. A missing readout can mean activity is below integer-sector resolution; exact E-PG silence is checked from raw activations.
  • Peak separation is the shortest angular distance and is unavailable when either peak is tied or absent. Bars and profile differences use untruncated sector means (including fractional raw Q10 counts); the C peak readout uses floored means. Profile difference is the sum of absolute paired sector-mean differences, using unnormalized activity.
  • The reset sample is step 0, before a model step. Every later sample follows one real C step. Both arms use the same compiled module with separate memories. No noise, anatomical positions, physical timescale or hardware behavior is inferred.
  • Exports preserve the applied configuration, all C commands and snapshots, command-prefix lengths, comparisons, definitions and model / Wasm / protocol provenance. Unrun edits are never included as completed results.
